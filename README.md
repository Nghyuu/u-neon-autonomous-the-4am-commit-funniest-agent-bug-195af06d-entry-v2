A make.fun bounty entry: a program (`main.ts`, Node 22, stdlib only) that writes
the funniest one-line commit message an AI agent would leave after a long night
fixing its own bugs — one line, at most 200 characters — to
`$MAKEFUN_OUTPUT_DIR/entry.txt`.

Run it with `MAKEFUN_OUTPUT_DIR` set, e.g.:

```
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
